# Reproducible lazygitrs Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a fresh machine reach a fully working lazygitrs — AI commit included — with `make install && make setup`.

**Architecture:** A new `contrib/` directory holds four shell entry points (`ai-commit`, `setup.sh`, `doctor.sh`, `setup-deps.sh`) plus a tracked `config.yml`. `setup.sh` creates two symlinks — the helper into `~/.local/bin` and the config into `~/.config/lazygitrs` — so nothing depends on where the repo is cloned and the config is version-controlled. Thin Makefile targets wrap each script.

**Tech Stack:** Bash, `jq`, `curl`, GNU Make, the DeepSeek chat-completions API.

> Also note: `lazyworktree` is an AUR package and this machine has `pacman` only,
> so Task 8 Step 5's expectation of zero warnings is unreachable without `paru`
> or `yay`.

## Global Constraints

Every task's requirements implicitly include these. Values are copied verbatim from the spec.

- **Symlink paths are exact:** `~/.local/bin/ai-lazygitrs-commit` → `<checkout>/contrib/ai-commit`, and `~/.config/lazygitrs/config.yml` → `<checkout>/contrib/config.yml`.
- **`contrib/config.yml` contains no machine-specific absolute paths.** Use `$HOME`. A literal `/home/<username>/` in that file is a defect.
- **`contrib/ai-commit` reads the diff on stdin.** `GenerateInputMode::for_command` (`src/git/ai_commit.rs:142`) grants repo-inspection mode only to `claude|codex|crabcode|opencode`; every other name gets `StdinDiff`.
- **Model defaults:** `AI_COMMIT_MODEL` = `deepseek-v4-flash`, `AI_COMMIT_MAX_TOKENS` = `3000`.
- **Never print secret values.** Check `DEEPSEEK_API_KEY` for presence only.
- **`setup.sh`:** idempotent, no sudo, never clobbers a real file (backs up to `<name>.bak`). Exits 0 when its own work succeeded even if the dependency report shows gaps.
- **`doctor.sh`:** read-only, changes nothing. Exits non-zero only on required-check failure.
- **`setup-deps.sh`:** opt-in, never invoked by `setup.sh`.
- **Makefile conventions:** `SHELL := /usr/bin/env bash` with `.SHELLFLAGS := -euo pipefail -c` are already set. Use `##@ Section` headers, a `.PHONY:` line before each target, and `## help text` after the target colon. Target names must be ≤16 characters — `help` aligns with `%-16s`.
- **README edits require `make sync-readme`.** `make readme-check` fails if `npm/README.md` has drifted.

```bash
# Minimal assertion helpers for the contrib/ shell tests.
# Source this file, call the assert_* helpers, then end with test_summary.

TESTS_RUN=0
TESTS_FAILED=0

_report_pass() {
    TESTS_RUN=$((TESTS_RUN + 1))
    printf '  \033[32m✓\033[0m %s\n' "$1"
}

_report_fail() {
    TESTS_RUN=$((TESTS_RUN + 1))
    TESTS_FAILED=$((TESTS_FAILED + 1))
    printf '  \033[31m✗\033[0m %s\n' "$1"
    printf '      %s\n' "$2"
}

# assert_eq <name> <expected> <actual>
assert_eq() {
    if [ "$2" = "$3" ]; then
        _report_pass "$1"
    else
        _report_fail "$1" "expected [$2], got [$3]"
    fi
}

# assert_contains <name> <haystack> <needle>
assert_contains() {
    case "$2" in
        *"$3"*) _report_pass "$1" ;;
        *) _report_fail "$1" "expected to contain [$3], got [$2]" ;;
    esac
}

test_summary() {
    printf '\n  %d test(s), %d failure(s)\n\n' "$TESTS_RUN" "$TESTS_FAILED"
    [ "$TESTS_FAILED" -eq 0 ]
}
```

- [ ] **Step 4: Write the helper**

Create `contrib/ai-commit`:

```bash
#!/usr/bin/env bash
# Generate a Conventional Commits message for a staged diff via the DeepSeek API.
#
# Contract with lazygitrs (git.commit.generateCommand):
#   stdin  - output of `git diff --cached`, piped in by lazygitrs
#   stdout - the commit message and nothing else
#   stderr - human-readable reason on failure (lazygitrs shows this in the UI)
#   exit   - 0 on success, non-zero on failure
#
# The diff arrives on stdin because GenerateInputMode::for_command
# (src/git/ai_commit.rs) reserves repo-inspection mode for the agent CLIs
# claude/codex/crabcode/opencode; any other command name gets StdinDiff.
#
# Environment:
#   DEEPSEEK_API_KEY          required (unless AI_COMMIT_STUB_RESPONSE is set)
#   AI_COMMIT_MODEL           default: deepseek-v4-flash
#   AI_COMMIT_API_URL         default: https://api.deepseek.com/chat/completions
#   AI_COMMIT_MAX_TOKENS      default: 3000
#   AI_COMMIT_MAX_DIFF_CHARS  default: 120000
#   AI_COMMIT_TIMEOUT         default: 120 (seconds)
#
# Test-only seams, used by contrib/test-ai-commit.sh:
#   AI_COMMIT_STUB_RESPONSE   path to a JSON file used instead of calling the API
#   AI_COMMIT_STUB_HTTP_CODE  HTTP status to simulate with the stub (default 200)

set -uo pipefail

MODEL="${AI_COMMIT_MODEL:-deepseek-v4-flash}"
API_URL="${AI_COMMIT_API_URL:-https://api.deepseek.com/chat/completions}"
MAX_TOKENS="${AI_COMMIT_MAX_TOKENS:-3000}"
MAX_DIFF_CHARS="${AI_COMMIT_MAX_DIFF_CHARS:-120000}"
TIMEOUT="${AI_COMMIT_TIMEOUT:-120}"
STUB_RESPONSE="${AI_COMMIT_STUB_RESPONSE:-}"

die() {
    printf '%s\n' "$*" >&2
    exit 1
}

command -v jq >/dev/null 2>&1 || die "jq is required but was not found on PATH."

diff="$(cat)"
printf '%s' "$diff" | grep -q '[^[:space:]]' || die "No staged changes to describe."

# Keep very large diffs inside a sane request size; the tail of a big change is
# usually its least informative part.
if [ "${#diff}" -gt "$MAX_DIFF_CHARS" ]; then
    diff="${diff:0:$MAX_DIFF_CHARS}"$'\n\n[diff truncated at '"$MAX_DIFF_CHARS"$' characters]'
fi

system_prompt='You write git commit messages. Follow the Conventional Commits specification.

Rules:
- First line: `<type>(<optional scope>): <summary>` in imperative mood, at most 72 characters, no trailing period.
- Then one blank line, then a body of "- " bullet points explaining what changed and why.
- Describe only what the diff actually shows. Never invent changes, issue numbers, or co-authors.
- Output the raw commit message only: no markdown code fences, no preamble, no trailing commentary.'

if [ -n "$STUB_RESPONSE" ]; then
    [ -f "$STUB_RESPONSE" ] || die "AI_COMMIT_STUB_RESPONSE points at a missing file: $STUB_RESPONSE"
    body="$(cat "$STUB_RESPONSE")"
    http_code="${AI_COMMIT_STUB_HTTP_CODE:-200}"
else
    [ -n "${DEEPSEEK_API_KEY:-}" ] || die "DEEPSEEK_API_KEY is not set (expected it exported from ~/.zshenv)."
    command -v curl >/dev/null 2>&1 || die "curl is required but was not found on PATH."

    payload="$(
        jq -n \
            --arg model "$MODEL" \
            --arg system "$system_prompt" \
            --arg user "Write a commit message for this staged diff:"$'\n\n'"$diff" \
            --argjson max_tokens "$MAX_TOKENS" \
            '{
                model: $model,
                stream: false,
                max_tokens: $max_tokens,
                messages: [
                    {role: "system", content: $system},
                    {role: "user", content: $user}
                ]
            }'
    )" || die "Failed to build the request payload."

    response="$(
        printf '%s' "$payload" | curl -sS -X POST "$API_URL" \
            -H "Content-Type: application/json" \
            -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
            --max-time "$TIMEOUT" \
            --data-binary @- \
            -w $'\n%{http_code}'
    )" || die "Request to the API failed (network error or timeout after ${TIMEOUT}s)."

    http_code="${response##*$'\n'}"
    body="${response%$'\n'*}"
fi

if [ "$http_code" != "200" ]; then
    api_error="$(printf '%s' "$body" | jq -r '.error.message // empty' 2>/dev/null)"
    [ -n "$api_error" ] || api_error="$(printf '%s' "$body" | head -c 500)"
    die "API returned HTTP ${http_code}: ${api_error}"
fi

message="$(printf '%s' "$body" | jq -r '.choices[0].message.content // ""' 2>/dev/null)"
finish_reason="$(printf '%s' "$body" | jq -r '.choices[0].finish_reason // ""' 2>/dev/null)"

if ! printf '%s' "$message" | grep -q '[^[:space:]]'; then
    # deepseek-v4-* are reasoning models: reasoning tokens are drawn from the
    # same max_tokens budget, so too small a budget yields empty content.
    if [ "$finish_reason" = "length" ]; then
        die "Model used its entire ${MAX_TOKENS}-token budget on reasoning and returned no message. Raise AI_COMMIT_MAX_TOKENS."
    fi
    die "Model returned an empty commit message (finish_reason: ${finish_reason:-unknown})."
fi

# Trim surrounding blank lines; lazygitrs strips any stray markdown fences.
printf '%s\n' "$(printf '%s' "$message" | sed -e '/./,$!d' -e :a -e '/^\n*$/{$d;N;ba' -e '}')"
```

### Task 3: The doctor

**Files:**
- Create: `contrib/doctor.sh`

**Interfaces:**
- Consumes: `contrib/config.yml` from Task 2 (parses `generateCommand` from the installed config, not from the repo copy).
- Produces: an executable `contrib/doctor.sh`. Exit 0 when all required checks pass, 1 otherwise. Task 4's `setup.sh` invokes it for its closing report and ignores its exit code.

- [ ] **Step 1: Write the doctor**

Create `contrib/doctor.sh`:

```bash
#!/usr/bin/env bash
# Diagnose a lazygitrs installation. Read-only: changes nothing.
#
# Exit codes:
#   0  every required check passed (optional tools may still be missing)
#   1  at least one required check failed
#
# Required : lazygitrs on PATH, config.yml present, generateCommand resolves,
#            jq, curl, and DEEPSEEK_API_KEY when generateCommand is configured
# Optional : delta, lazyworktree

set -uo pipefail

CONFIG_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/lazygitrs"
CONFIG_FILE="$CONFIG_DIR/config.yml"
FAILED=0

ok()   { printf '  \033[32m✓\033[0m %s\n' "$*"; }
warn() { printf '  \033[33m!\033[0m %s\n' "$*"; }
bad()  { printf '  \033[31m✗\033[0m %s\n' "$*"; FAILED=1; }

# Pull the generateCommand value from a lazygit-style config.yml. Deliberately
# simple: it matches the common single-line `generateCommand: <value>` form and
# strips one layer of surrounding quotes.
extract_generate_command() {
    sed -n 's/^[[:space:]]*generateCommand:[[:space:]]*//p' "$1" \
        | head -n1 \
        | sed -e "s/^'\(.*\)'\$/\1/" -e 's/^"\(.*\)"$/\1/'
}

printf '\n  lazygitrs doctor\n\n'

# --- the binary -----------------------------------------------------------
if command -v lazygitrs >/dev/null 2>&1; then
    ok "lazygitrs on PATH ($(lazygitrs --version 2>/dev/null | head -n1))"
else
    bad "lazygitrs not on PATH (required) — run: make install"
fi

# --- the config -----------------------------------------------------------
if [ -L "$CONFIG_FILE" ]; then
    if [ -e "$CONFIG_FILE" ]; then
        ok "config.yml → $(readlink "$CONFIG_FILE")"
    else
        bad "config.yml is a broken symlink → $(readlink "$CONFIG_FILE") (required) — run: make setup"
    fi
elif [ -f "$CONFIG_FILE" ]; then
    warn "config.yml is a regular file, not the tracked symlink — run: make setup"
else
    bad "config.yml missing at $CONFIG_FILE (required) — run: make setup"
fi

# --- generateCommand ------------------------------------------------------
gen_cmd=""
if [ -e "$CONFIG_FILE" ]; then
    gen_cmd="$(extract_generate_command "$CONFIG_FILE")"
fi

if [ -z "$gen_cmd" ]; then
    warn "no generateCommand configured — AI commit is disabled"
else
    case "$gen_cmd" in
        *'$('* | *'&&'* | *'|'* | *';'*)
            warn "generateCommand is a shell expression; skipping the executable check"
            ;;
        *)
            first_word="${gen_cmd%% *}"
            case "$first_word" in
                '$HOME'*)   first_word="$HOME${first_word#\$HOME}" ;;
                '${HOME}'*) first_word="$HOME${first_word#\$\{HOME\}}" ;;
                '~'*)       first_word="$HOME${first_word#\~}" ;;
            esac

            case "$first_word" in
                *=*)
                    warn "generateCommand starts with an env assignment; skipping the executable check"
                    ;;
                *)
                    if command -v "$first_word" >/dev/null 2>&1; then
                        ok "generateCommand → $first_word"
                    else
                        bad "generateCommand → $first_word does not exist or is not executable (required)"
                    fi
                    ;;
            esac
            ;;
    esac
fi

# --- dependencies ---------------------------------------------------------
for required in jq curl; do
    if command -v "$required" >/dev/null 2>&1; then
        ok "$required found"
    else
        bad "$required missing (required) — run: make setup-deps"
    fi
done

if command -v delta >/dev/null 2>&1; then
    ok "delta found"
else
    warn "delta missing (optional) — used by git.pagers; run: make setup-deps"
fi

if command -v lazyworktree >/dev/null 2>&1; then
    ok "lazyworktree found"
else
    warn "lazyworktree missing (optional) — used by the W custom command; run: make setup-deps"
fi

# --- the API key ----------------------------------------------------------
# Presence only. The value is never printed.
if [ -n "$gen_cmd" ]; then
    if [ -n "${DEEPSEEK_API_KEY:-}" ]; then
        ok "DEEPSEEK_API_KEY is set"
    else
        bad "DEEPSEEK_API_KEY is not set (required by generateCommand) — add to ~/.zshenv: export DEEPSEEK_API_KEY=<key>"
    fi
fi

printf '\n'
if [ "$FAILED" -eq 0 ]; then
    printf '  \033[32mall required checks passed\033[0m\n\n'
else
    printf '  \033[31mone or more required checks failed\033[0m\n\n'
fi

exit "$FAILED"
```

```bash
#!/usr/bin/env bash
# Wire this checkout into the current user's environment. Idempotent, no sudo.
#
#   ~/.local/bin/ai-lazygitrs-commit -> <checkout>/contrib/ai-commit
#   ~/.config/lazygitrs/config.yml   -> <checkout>/contrib/config.yml
#
# The helper is linked into ~/.local/bin rather than referenced in the config by
# its checkout path: if generateCommand named a checkout path, cloning to a
# different directory on another machine would break it — the same class of bug
# this setup exists to prevent.
#
# Exits 0 whenever the symlink work succeeded, even when the closing report
# lists missing tools: on a fresh machine jq/delta are legitimately absent until
# `make setup-deps` runs, and `make install setup` must not look like a failure.

set -euo pipefail

HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
BIN_DIR="$HOME/.local/bin"
CONFIG_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/lazygitrs"

link_into_place() { # target linkpath
    local target="$1" linkpath="$2"

    if [ -L "$linkpath" ]; then
        if [ "$(readlink "$linkpath")" = "$target" ]; then
            printf '  = already linked: %s\n' "$linkpath"
            return 0
        fi
        rm -f "$linkpath"
    elif [ -e "$linkpath" ]; then
        mv "$linkpath" "$linkpath.bak"
        printf '  ! existing file backed up: %s -> %s.bak\n' "$linkpath" "$linkpath"
    fi

    ln -s "$target" "$linkpath"
    printf '  + linked: %s -> %s\n' "$linkpath" "$target"
}

printf '\n  lazygitrs setup\n\n'

mkdir -p "$BIN_DIR" "$CONFIG_DIR"
chmod +x "$HERE/ai-commit" "$HERE/doctor.sh"

link_into_place "$HERE/ai-commit" "$BIN_DIR/ai-lazygitrs-commit"
link_into_place "$HERE/config.yml" "$CONFIG_DIR/config.yml"

case ":$PATH:" in
    *":$BIN_DIR:"*) ;;
    *) printf '  ! %s is not on PATH — add it so generateCommand resolves\n' "$BIN_DIR" ;;
esac

# The report is informational; a missing optional tool must not fail setup.
"$HERE/doctor.sh" || true

exit 0
```

```bash
#!/usr/bin/env bash
# Install the tools lazygitrs' config references. Opt-in: setup.sh never calls
# this, because installing system packages should be an explicit choice.
#
#   jq, git-delta   official Arch repositories
#   lazyworktree    AUR — needs paru or yay
#
# Pass --dry-run to print the commands without running them.

set -euo pipefail

DRY_RUN=0
if [ "${1:-}" = "--dry-run" ]; then
    DRY_RUN=1
fi

run() {
    if [ "$DRY_RUN" -eq 1 ]; then
        printf '  would run: %s\n' "$*"
    else
        printf '  running: %s\n' "$*"
        "$@"
    fi
}

printf '\n  lazygitrs setup-deps\n\n'

AUR_HELPER=""
for candidate in paru yay; do
    if command -v "$candidate" >/dev/null 2>&1; then
        AUR_HELPER="$candidate"
        break
    fi
done

if [ -n "$AUR_HELPER" ]; then
    run "$AUR_HELPER" -S --needed --noconfirm jq git-delta lazyworktree
elif command -v pacman >/dev/null 2>&1; then
    run sudo pacman -S --needed --noconfirm jq git-delta
    printf '  ! lazyworktree is an AUR package — install paru or yay, then re-run\n'
else
    printf '  \033[31m✗\033[0m no supported package manager found (looked for paru, yay, pacman)\n' >&2
    printf '    install these manually: jq, git-delta, lazyworktree\n' >&2
    exit 1
fi

printf '\n  done — verify with: make doctor\n\n'
```
